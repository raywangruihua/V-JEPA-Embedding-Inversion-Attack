# Project Summary

Most of the code in this project was generated by Claude.

## Thesis

An embedding inversion attack should be possible for JEPA[^1] video models the same way it has been shown for text [1] and images [2], without any query access to the target model. The approach is to first intercept V-JEPA embeddings off a compromised embodied AI network, then align them to the latent space of a known white-box generative model using a Gromov-Wasserstein distance based approach, finally decoding them with that model to reconstruct the original video. This relies on the Platonic Representation Hypothesis [3]: SOTA models have converged enough in their latent spaces for an unsupervised alignment to work.

The aim of this project changes slightly towards the end, where I decide to extract embedding information into the text domain instead. 

[^1]: JEPA is a world model architecture that aims to encode information while being able to predict future latents with high accuracy, thus training a model that "understands" real life physics

Target model: V-JEPA (ViT-L, D = 1024). Reconstruction model: LTX-2 VAE. Dataset: Something-Something V2.

## Completed Tasks

1. Set up V-JEPA (the target model, encoding only since the decoder weights are not open source) and LTX-2 (the white box model, encoding and decoding) and wrote inference scripts for both.
4. Implemented Monte Carlo based Gromov-Wasserstein estimation to compare the two latent spaces, which is less computationally intensive on large datasets.
5. Implemented GW alignment based on [4], ran it on the two embedding datasets, and decoded the mapped target embeddings with the LTX-2 decoder.
6. Trained supervised adaptors (linear, MLP, convolutional) from V-JEPA to LTX-2 VAE latents, to find out what the ceiling for pixel reconstruction actually is.
7. Trained a conditional diffusion adaptor for the same mapping, following the encoder -> predictor -> conditional diffusion arrangement used in the official `facebookresearch/jepa` results to see if it outperforms supervised adaptors.
8. Attempted to upscale the decoded videos with the LTX-2 19B IC LoRA detailer.
9. Trained learned projectors from V-JEPA into a frozen LLM's input space (Qwen2.5-1.5B-Instruct, 64 soft tokens), and read the clip back out as language instead of pixels.
10. Ran a nearest-neighbour baseline and a full control table for the text results.

## Results

### Structural similarity of the two latent spaces

| Dataset A | Dataset B | Mean GW |
| --------- | --------- | ------- |
| V-JEPA    | LTX-2     | 0.21    |
| V-JEPA    | V-JEPA    | 0.00    |
| LTX-2     | LTX-2     | 0.03    |

Smaller is better, 0 is a perfect match. This looked promising at first, and suggested the two spaces match decently in structure.

### Gromov-Wasserstein alignment

The alignment did not work. Aligned V-JEPA latents decoded into nonsense videos. Adding more data did not help, and running the alignment on two sets of embeddings from the *same* model actually diverged, which should be the easiest possible case. So either the implementation is wrong, GW cannot align video embedding spaces, or the two latent spaces are simply too different for it. I could not distinguish between these three.

### Supervised pixel reconstruction

Since the unsupervised route failed, I trained supervised adaptors to check whether the mapping is possible *at all*. It is, but only weakly. The adaptor reached R² ≈ 0.30 overall and only 0.03 in the detail band, and forcing the variance to match at 0.6 and 1.0 still did not produce shapes — so the high-frequency content is absent from the prediction, not just under-scaled.

The conditional diffusion adaptor was the best of the lot and sharpened object boundaries, but still recovered no recognisable action. Colour, rough position and overall shape of objects generally transfer over. Everything else is a mess of pixels.

The IC LoRA detailer produced high quality video that had nothing to do with the original clip most of the time. It makes the warbled input coherent by inventing content, which is the opposite of what a reconstruction needs. Training my own detailer on V-JEPA-decoded video rather than blurry video would have been the right move, but I do not have the VRAM for it.

### Text reconstruction

Reading the embedding out as language works much better, because pixel level detail does not have to be reconstructed. Trained on 4500 clips, evaluated on 500 held out.

| Projector | Action acc | Object recall | Word F1 | Retrieval top-1 | Median rank |
| --------- | ---------- | ------------- | ------- | --------------- | ----------- |
| NN baseline | 0.130 | 0.156 | 0.185 | — | — |
| mean      | 0.194 | 0.183 | 0.248 | 0.266 | 5 |
| pool      | 0.144 | 0.146 | 0.208 | 0.207 | 8 |
| perceiver | 0.148 | 0.172 | 0.240 | 0.227 | 6 |

Chance action accuracy is 0.6% (174 SSv2 templates), chance retrieval top-1 is 0.4%.

The controls matter more than the headline numbers here, because a frozen LLM will write a confident, well-formed SSv2 caption when handed pure noise. Conditioning on another clip's real embedding (`shuffle`) drops action accuracy to 0.004–0.008 across all three projectors, and random and zero conditioning behave the same. So the gap between 0.148 and 0.008 is real leakage and not the LLM's prior talking.

Two things I did not expect:

1. **`mean` won.** It pools every patch into a single vector and throws away all spatial and temporal structure, and it still beat both `pool` and `perceiver` on action accuracy and retrieval. The honest reading is that V-JEPA leaks a gist vector and not much finer than that. It is also the largest of the three models (~208M parameters against ~53M and ~9M), so this is not a case of the floor being starved.
2. Verbs are generally described correctly, but nouns are frequently hallucinated — "lifting a pen up with pen on it" for a reference of "lifting flash card up completely without letting it drop down". The action survives the encoding, the object does not.

## Findings

1. Original video inputs cannot be reconstructed from V-JEPA embeddings. Colour, rough shape and position can be recovered, but the output is undecipherable without a generative model filling in the gaps, and at that point the coherent parts are invented rather than reconstructed.
2. GW alignment did not produce a working unsupervised route, and I was not able to determine why.
3. The attacker will have more success using a pre-trained classifier to get labels from intercepted V-JEPA embeddings rather than attempting to reconstruct videos, since only the semantics are encoded.

## Known Open Items

1. Training on SSv2 labels alone means the model can only ever speak SSv2 idiom. A re-captioning pass with a VLM is what would turn the action/object split into a real per-attribute leakage profile covering objects, colour, background and camera.

## Future Direction

Temporal Gromov-Wasserstein alignment on embedding trajectories. Otherwise, staying in the text domain and re-captioning training data with a VLM for the LLM approach might improve results.
